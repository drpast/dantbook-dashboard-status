# DantBook Dashboard Status

Public-safe status source for the DantBook floating dashboard.

- Status JSON: [status.json](./status.json)
- Raw JSON endpoint: https://raw.githubusercontent.com/drpast/dantbook-dashboard-status/main/status.json
- The dashboard app should poll this endpoint every 30 seconds and retain its last successful data for offline display.
- This repository is for public project-progress metadata only. Never store patient data, clinic records, credentials, or private source code here.
- Progress figures are estimates, not automated code metrics.
